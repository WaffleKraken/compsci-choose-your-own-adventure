# Bosses

One class per boss from the [Bosses page](../../docs/story/04-bosses.md). The road picks 3 of the 5 at random each playthrough. Each file starts with `package bosses;`.

| Suggested file | Boss |
|----------------|------|
| `Mugger.java` | Boss 1: Mugger (fight or flight) |
| `Beggar.java` | Boss 2: Beggar (give $10 or leave) |
| `Samaritan.java` | Boss 3: Kind Samaritan (take the ride or not) |
| `Hunger.java` | Boss 4: Hunger (Popeyes, -$8, or Dine and Dash ending if you can't pay) |
| `Snake.java` | Boss 5: Snake (ointment or 30% chance of dying) |
